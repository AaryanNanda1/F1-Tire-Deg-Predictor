# Cliff and useful-life validation

Analysis-only results from frozen reviewed 2023 race-stint labels. Observed curves are fuel-corrected and predicted curves are generated by leakage-safe 2022-to-2023 evaluation. Detector threshold search uses a grouped development/holdout split by Grand Prix. Useful-life intervals are operational ±1/±2/±3 lap bands, not formal confidence intervals. The predicted-curve fit uses the documented analysis-only training-row cap to avoid dense HGB resource exhaustion. Production defaults, training data, PCA implementation, and model artifacts were not changed.
